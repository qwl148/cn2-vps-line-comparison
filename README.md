## CN2、CMIN2、9929线路到底差在哪

不少文章把这些线路混在一起讲，但它们实际属于不同运营商的骨干网，速度和稳定性差别挺大。

**CN2 GIA**（China Telecom Next Carrier Network Global Internet Access）是电信的高端国际骨干网，ASN号AS4809。特点是全程单独通道，晚高峰不和普通用户抢带宽，延迟稳定。CN2还有个便宜版本叫CN2 GT（Global Transit），出国部分走CN2，但国内部分和普通163骨干网共享，晚高峰会卡。

**CMIN2**（China Mobile International Next-generation Network）是中国移动的高端国际骨干网，ASN号AS58807。从洛杉矶直连上海入口，延迟稳定在126毫秒左右，晚高峰不掉速。你可以粗暴地把它理解成"移动版的CN2 GIA"。

**9929**（China Unicom Premium，ASN号AS9929）是联通的高端线路CUII，比联通普通的4837线路等级高。

关键来了：很多商家说的"三网优化"实际只优化了一部分。比如只有移动方向走CMIN2，电信和联通还是普通线路；或者只有回程（从服务器返回你家）走优化线路，去程（你访问服务器）还是绕路。真正"三网回程强制CMIN2"指的是，不管你家里是电信、联通还是移动宽带，数据返回时都走CMIN2专线。
